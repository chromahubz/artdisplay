# Mockup Images

Place your mockup background images here:

## Required Images

1. **frame1.jpg** - Classic Frame
   - Traditional wooden or gold frame on light background
   - Recommended size: 2000x2000px minimum
   - Format: JPG or PNG

2. **frame2.jpg** - Modern Frame
   - Contemporary black frame on dark or minimal background
   - Recommended size: 2000x2000px minimum
   - Format: JPG or PNG

3. **gallery-wall.jpg** - Gallery Wall
   - Clean white gallery wall
   - Recommended size: 2000x2000px minimum
   - Format: JPG or PNG

## How to Add Images

1. Download high-quality images from free sources (see MOCKUP_SOURCES.md)
2. Rename them to match the filenames above
3. Place them in this folder (`/public/mockups/`)
4. Restart the development server
5. The app will automatically load and display them

## Image Optimization

Before adding images, optimize them:
- Use https://tinypng.com/ to compress
- Target size: 300-500KB per image
- Keep resolution high but file size small

## Fallback

If images are missing, the app will show a solid color background with a subtle pattern instead.
